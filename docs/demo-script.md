# Как подготовлена демонстрация

[← На главную](../README.md) · [Галерея](gallery.md) · [Видеообзор](../assets/video/interface-tour.webm)

## Среда

Материалы сняты 16 октября 2026 года в Chromium. Использована отдельная временная копия frontend проекта с исходным интерфейсом. Переменные окружения рабочего приложения в копию не переносились.

Для закрытых страниц отдельный локальный API возвращал синтетический профиль, каталог, мощности и объекты. Разрешены только запросы чтения; запросы изменения данных отклонялись. Реальная база, Keycloak, хранилище документов и платёжные сервисы в съёмке не участвовали.

## Содержание видео

1. Главная страница и назначение приложения.
2. Каталог продукции.
3. Карточка товара.
4. Производственные мощности.
5. Форма новой мощности без отправки.
6. Объекты компании.

В видео добавлена подпись о демонстрационных данных. Формат — WebM, без звука. При отсутствии встроенного воспроизведения в GitHub файл можно скачать и открыть в браузере или видеоплеере с поддержкой WebM.

## Что подтверждают материалы

Галерея показывает фактический внешний вид страниц frontend на указанных данных. Видео показывает обзор экранов и навигацию по ним. Это не запись сквозной интеграционной приёмки: доступ, резервирование, документы, сделки и платежи проверяются отдельно.

Переходы в записи открываются напрямую; процесс регистрации и аутентификации через IdP не записывался. Синтетические компании, имена и объёмы не относятся к реальным клиентам.
