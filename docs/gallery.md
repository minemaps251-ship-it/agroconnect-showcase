# Интерфейс AgroConnect

[← На главную](../README.md) · [Видеообзор](https://minemaps251-ship-it.github.io/agroconnect-showcase/)

Здесь я показываю реальные страницы frontend на вымышленных данных. Кадры кабинета подготовлены с отдельным API только для чтения; формы, сделки и платежи не выполнялись.

Это предыдущий демонстрационный срез интерфейса. Текущие кабинеты дорабатывались; новые кадры я добавлю после авторизованной съёмки на безопасных данных.
